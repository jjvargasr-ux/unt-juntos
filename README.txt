UNT Juntos - versión de interfaz mejorada

Archivos:
- index.html: pantallas, registro, grupos y explicación de modalidades de traslado.
- styles.css: diseño visual, colores y componentes adaptables.
- app.js: lógica del prototipo local.
- logo.svg: logotipo original de UNT Juntos utilizado en la aplicación y como favicon.
- privacidad.html: información de privacidad.

Para probar:
1. Extrae el ZIP.
2. Abre la carpeta completa en Visual Studio Code.
3. Abre index.html con Live Server.

Importante:
Esta versión conserva el almacenamiento local del prototipo. Los grupos y mensajes no se comparten entre dispositivos ni usuarios reales. La verificación por código al correo tampoco está conectada a un proveedor de autenticación. Para habilitar esas funciones se necesita integrar un backend, autenticación y una base de datos compartida.

Las modalidades descritas en la aplicación son acuerdos voluntarios entre estudiantes. UNT Juntos no proporciona vehículos, conductores, pasajes ni gestiona pagos.
No se solicita ni se almacena la contraseña del correo institucional.
